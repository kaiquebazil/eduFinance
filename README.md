# EduFinance Web

Aplicação web estática do EduFinance, publicada pelo GitHub Pages a partir da raiz do repositório.

## Estrutura

- `index.html`: página de entrada.
- `assets/css` e `assets/js`: estilos e código da aplicação.
- `assets/icons`: ícones usados pelo site e pelo PWA.
- `examples`: backup de exemplo para importação.
- `manifest.webmanifest` e `sw.js`: instalação e suporte offline.
- `CNAME`: domínio personalizado do GitHub Pages.

Para testar localmente, sirva a raiz com `python -m http.server 8000` e abra `http://localhost:8000`.
